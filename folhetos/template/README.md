# Modelo LOC IEAB 2015

`loc-ieab-2015.html` é a base dos folhetos criados com:

```bash
python3 build_folheto.py --new AAAA-MM-DD
```

## Fonte litúrgica

- *Livro de Oração Comum da Igreja Episcopal Anglicana do Brasil*, edição de 2015, reimpressão de 2021.
- **Santa Comunhão sob Circunstâncias Especiais**, páginas 355–366.
- Cópia pública: <https://santosanglicana.org.br/wp-content/uploads/2023/09/LOC_2021_PT.pdf>

O modelo reproduz a celebração comunitária com Sacramento Reservado: Liturgia da Palavra, Ação de Graças pela Partilha do Sacramento, Comunhão, Pós-Comunhão e Oração Conclusiva.

## Limites do ministro local

- Não há Oração Eucarística, epiclese, nova consagração ou Partir do Pão.
- As Palavras da Instituição não são recitadas como ato ritual.
- A confissão termina com a oração deprecativa dita por toda a assembleia.
- O encerramento usa “O Senhor **nos** abençoe”, não uma bênção sacerdotal sobre o povo.
- O Sacramento deve ter sido previamente consagrado e a pessoa oficiante deve estar autorizada pela autoridade episcopal.

## Conteúdo manual

Antes de publicar, preencher:

- hino processional e cântico de comunhão;
- título, referências e rubrica do sermão;
- tópicos das Orações do Povo;
- nome da comunidade onde o Sacramento foi consagrado.

O cabeçalho, a celebração menor, a coleta e as leituras vêm da API Estêvão com o livro `loc_2015`.
